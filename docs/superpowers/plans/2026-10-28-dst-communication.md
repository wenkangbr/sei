# 饥荒游戏内沟通实现计划

目标：在主持人游戏画面显示伙伴三维与动作，点击卡片聊天，并通过菜单选择跟随、砍树、挖矿、保护和存放材料。

方案：服务器辅助模组通过现有心跳提供状态；客户端界面从本机发现服务读取状态，用游戏原生聊天通道发送自由文本和快捷指令。客户端和服务器界面分开，洞穴服务器独立进程也可读取同一状态。游戏包与发布流程必须包含修改后的两个模组。

1. 为状态心跳、过期清理和只读访问编写并运行测试。
2. 实现客户端卡片、原生聊天输入和快捷按钮，并安装客户端模组。
3. 配置自有游戏包和发布流程，保证新版本不会加载官方旧模组。
4. 运行相关测试、构建与真实游戏验证；未能完成的部分明确报告。
